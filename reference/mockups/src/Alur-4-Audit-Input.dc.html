Prinsip
1. Satu format untuk tiga hal: isi Google Sheet, file Data lengkap, dan template import.2. Aplikasi tidak membaca format bursa atau pialang. Import hanya menerima template Hartafolio; selebihnya input manual.3. Satu baris = satu kejadian. Jenis kejadian ada di kolom Jenis, jadi tidak ada pilihan mode.4. Import tidak pernah menimpa. Baris yang sudah ada dilewati, yang bermasalah ditunjukkan nomor barisnya.5. Form Catat memakai kolom yang sama dengan template, supaya 1–10 transaksi lebih cepat lewat aplikasi.
