Template Hartafolio · format baku

Satu format untuk template import, isi Google Sheet, dan file Data lengkap. Import hanya menerima format ini. Template diunduh per akun, jadi dropdown sudah berisi anggota, lokasi, dan aset Anda.

Sheet TransaksiSatu baris = satu kejadian. Wajib: Tanggal, Jenis, Anggota, Aset, Jumlah, Lokasi.

Aturan import
Kondisi saat importYang terjadi
Bukan template (judul kolom wajib tidak ada)Ditolak dengan daftar kolom yang hilang + tombol Unduh template. Tidak ada cocokkan kolom.
Nama baru (anggota, lokasi, aset)Dibuat otomatis; aset di luar katalog tanpa baris di sheet Aset dilengkapi di Periksa.
Baris tidak bisa dibacaDitunjukkan nomor barisnya, dilewati. Perbaiki lalu import lagi; baris yang sudah masuk tidak dobel.
Baris sama sudah adaDilewati (No. referensi sama, atau Tanggal+Anggota+Aset+Lokasi+Jumlah+Harga).
Saldo awal untuk aset yang sudah punya catatanDilewati; tampil tercatat vs di file.
Nilai bulanan untuk bulan yang sudah tercatatDilewati.
File Data lengkapDiterima seperti template; dipakai untuk memulihkan atau pindah sheet.
Kolom tambahanDiabaikan. Data pribadi tidak pernah disimpan.
